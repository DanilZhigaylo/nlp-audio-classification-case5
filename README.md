## 1. Описание задачи и целей
Целью данного проекта является построение ML/NLP пайплайна для автоматического анализа и классификации текстового и аудиосодержимого на предмет наличия ненормативной лексики, токсичности, оскорблений и недопустимого контента.

---

## 2. Техническое описание найденных датасетов

### **Датасет 1: Russian Language Toxic Comments Dataset (Основной текстовый датасет)**
* **Источник:** Kaggle / Hugging Face Datasets (`russian_toxic_comments`).
* **Структура и формат:** Файл в формате `.csv`. Основные колонки:
  * `comment_text` (string) — текст сообщения (или результат транскрипции аудио через ASR-модель).
  * `toxic` (float/int) — бинарная метка категории (0 — нейтральный/безопасный контент, 1 — токсичный контент).
* **Объем:** 14 412 размеченных русскоязычных комментариев.
* **Качество разметки:** Высокое качество, ручная разметка экспертами с предварительной очисткой от спама и дубликатов.
* **Применимость:** Используется как основной обучающий корпус для тонкой настройки (fine-tuning) NLP-классификаторов на базе RuBERT/RoBERTa.

### **Датасет 2: CREMA-D / Audio Emotional Speech Dataset (Дополнительный аудио-корпус)**
* **Источник:** Открытый академический речевой корпус.
* **Структура и формат:** Коллекция аудиозаписей в формате `.wav` (PCM 16-bit, частота дискретизации 16 kHz) со связующим табличным файлом метаданных (`metadata.csv`).
  * `filename` — имя аудиофайла.
  * `emotion` — разметка тона речи (`anger`, `disgust`, `neutral`, `sadness`).
* **Объем:** Более 7 400 речевых аудиозаписей от различных дикторов.
* **Качество разметки:** Лабораторное качество записи и проверенная разметка академическими асессорами.
* **Применимость:** Применяется для извлечения спектральных и акустических признаков (MFCC, Mel-spectrograms) с целью детекции агрессивного тона речи в аудиопотоке.

---

## 3. Потенциальные источники для сбора дополнительных данных
1. **Open Speech Data (Mozilla Common Voice - Russian):** Корпус русской речи для балансировки классификатора и дообучения ASR-модели (Whisper/Vosk).
2. **Аудио-аугментация (Аудио-шумы):** Использование библиотеки `audiomentations` для наложения фонового шума, изменения скорости и тональности речи для улучшения устойчивости модели в реальных условиях.
