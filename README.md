# Кейс 5: Классификация текстовых сообщений (без трансформеров)

**Исполнитель:** Жигайло Данил Алексеевич

## Описание решения
* **Датасет:** `dataset.txt` (из `dataset.txt.zip`, разобрано **248 290** строк; классы: `NORMAL`, `INSULT`, `THREAT`, `OBSCENITY`).
* **Предобработка:** единая функция `preprocess_text` (приведение к нижнему регистру, замена `ё` на `е`, удаление ссылок/хештегов и лишних символов, нормализация пробелов).
* **Модели и ансамбль:** `TfidfVectorizer` (униграммы и биграммы слов) + взвешенный ансамбль `LogisticRegression` (вес `0.47`) и `ComplementNB` (вес `0.53`), веса подобраны на валидации (`val`).
* **Пост-обработка и анализ ошибок:** разбор матрицы ошибок и ошибочных примеров на тесте (`37 239` объектов, `1 851` ошибка до пост-обработки) + подбор множителя `1.90` для класса `OBSCENITY` на валидации.

## Итоговые метрики на тесте (после пост-обработки)
* **Test Accuracy:** `0.9516` (95,16%)
* **Test Macro F1:** `0.8045`
